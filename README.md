
# olobase-php

Olobase 3.x Php Backend


## Modules

Installing a module

```sh
php bin/module.php --install="Authentication"
```


Removing a module

```sh
php bin/module.php --remove="Authentication"
```


## Open API

Build swagger schemas

```
composer swagger-debug
```

Debug all files for syntax errors

```
composer swagger-debug
```
